Open data

Every table on ByTheRank is published as CSV and JSON, with the same numbers, order and scores as the page. Licence: CC BY 4.0: use them freely; please link to the page you took them from. The source data are U.S. government works (public domain). In a table, products with equal scores share a rank; the JSON marks them "tied": true. Columns starting input: (JSON inputs) are the certified values behind a computed column, and the JSON's computed_from gives the rates, so the computed numbers can be checked from the file alone.
