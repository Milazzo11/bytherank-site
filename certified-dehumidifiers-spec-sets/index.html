Method

A listing is one row of the certified list. A model is a distinct certifying partner plus model number (letters and digits only). A spec set is every listing with identical certified values on all 11 reported fields (annual_energy_consumption_kwh_yr, connected_capable, connected_features, connects_using, dehumidifier_efficiency_integrated_energy_factor_l_kwh_, dehumidifier_type, dehumidifier_water_removal_capacity_per_appendix_x1_pints_day, meets_most_efficient_criteria, refrigerant_charge_oz, refrigerant_type, whole_home_dehumidifier_case_volume_ft3); identity, dates and market notes are not compared, refrigerant names are normalised (R-32 = R32 = HFC-32). Identical certified values do not show who built a product. How this is made.

FAQ

Does a shared spec set mean two brands sell the same product?

It means every certified value reported for them is identical (11 fields). The list does not report dimensions or parts, so we say identical certified values, nothing more.

Where do these numbers come from?

From the U.S. EPA ENERGY STAR certified Dehumidifiers dataset (retrieved 2026-11-01). We group listings by their certified values and count; we did not test any unit.
